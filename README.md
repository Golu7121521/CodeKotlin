# All Video Downloader

A modern, Material 3 Flutter Android app for previewing and downloading videos from publicly accessible, authorized URLs.

## ⚖️ Legal & Usage Note

This app is designed to work **only** with video URLs that are publicly accessible and legally downloadable. It:

- Does **not** attempt to bypass DRM, paywalls, logins, or any platform access restriction.
- Only downloads media from the direct `download_url` returned by the configured backend API for a given input URL.
- Assumes the backend API itself only resolves content the user is authorized to access.

You are responsible for ensuring you have the right to download any content you process with this app.

## Features

- Paste, clear, and clipboard-aware URL input with validation
- Backend API integration for resolving a video URL into a direct media URL
- Automatic temporary preview download (cached, not saved permanently until confirmed)
- Mini preview card with inline playback, animated entrance
- Fullscreen video player with:
  - Two-finger pinch-to-zoom and pan (1.0x–4.0x), double-tap to toggle zoom
  - Seek forward/back, scrub bar, playback speed, lock controls, auto-hide controls
- One-tap download that **reuses** the already-downloaded temp file (no re-download)
- Animated download progress (percentage, size, speed, remaining time)
- Downloads screen (Active / Completed / Failed) with pause/cancel/retry-style actions
- History screen with search, filters (All / Recent / Large files), sorting, grid/list toggle
- Settings: theme (light/dark/system), download behavior, player defaults, storage management
- Share videos out via Android `FileProvider` (no raw `file://` URIs)
- Receive shared video URLs from other apps via Android share intent
- Local SQLite-backed download history with corruption recovery
- Light/dark Material 3 themes, onboarding flow, animated splash screen
- Scoped, app-specific storage — no broad storage permission requested

## Setup

```bash
flutter pub get
```

Ensure `android/local.properties` points `flutter.sdk` and `sdk.dir` at your local installations (this file is normally auto-generated by Android Studio, or overwritten by CI).

## API Integration

The app calls:

```
https://allinonedownloader-api.onrender.com/download?url=<url-encoded video URL>
```

and expects a JSON response containing at least:

```json
{ "download_url": "https://example.com/video.mp4" }
```

Optional fields the app also reads if present: `title`, `file_size`, `duration_ms`, `thumbnail`.

The request is made asynchronously (never on the UI thread), with a 30-second timeout, and all failure modes (timeout, no connection, server error, invalid/empty JSON, missing `download_url`) surface a friendly, specific error message to the user.

If an API key becomes required in the future, do not hardcode it — inject it via a build-time `--dart-define` or a local, gitignored configuration file instead.

## Temporary Preview & Download Behavior

1. When a URL is submitted, the app calls the API, then streams the resolved `download_url` into the app's **temporary cache directory** (not permanent storage).
2. A mini preview card plays this temp file directly.
3. If the user taps **Download**, the existing temp file is **moved** (or copied, if a cross-volume rename fails) into permanent, app-scoped storage — the video is **not** re-downloaded.
4. If the user does not download, the temp file is cleaned up when the preview is dismissed, and any orphaned temp files older than 6 hours are swept on the next app launch.

## Build Instructions

### Debug build

```bash
flutter run
```

### Release APK

```bash
flutter build apk --release
```

Output: `build/app/outputs/flutter-apk/app-release.apk`

```bash
flutter build appbundle --release
```

## GitHub Actions

`.github/workflows/build.yml` runs on every push/PR to `main`/`master`:

1. **analyze_and_test**: `flutter pub get` → `flutter analyze` → `flutter test`
2. **build_android**: builds `app-release.apk` and `app-release.aab`, uploaded as workflow artifacts

To get the APK from CI: open the workflow run under the **Actions** tab → download the `app-release.apk` artifact.

## Troubleshooting

| Issue | Fix |
|---|---|
| `flutter.sdk not set in local.properties` | Set `flutter.sdk=/path/to/flutter` in `android/local.properties`, or let Android Studio regenerate it. |
| Gradle sync fails on first open | Run `flutter pub get`, then re-sync; ensure JDK 17 is selected in Android Studio. |
| Video preview doesn't play | Confirm the resolved `download_url` is a direct, playable media URL and reachable from the device network. |
| "Server is temporarily unavailable" | The backend API may be cold-starting (Render free tier) — retry after a few seconds. |
| Share button does nothing | Ensure the file exists at `localPath`; sharing uses `FileProvider`, so raw file paths outside the configured provider paths will fail silently by design. |

## Storage Behavior

- **Temporary preview cache**: app cache directory, cleared automatically on unconfirmed downloads and swept for orphans on startup.
- **Permanent downloads**: app-scoped external storage (`Movies/Downloads` under the app's external files directory) — no storage permission required on modern Android.
